# WebFace42M Local Target

This folder is the canonical adjacent import target for the WF42M ceiling pipeline.

- Expected published ceiling: RetinaFace-class 5-point alignment, 112x112 normalized crop
- Local proxy setting: smaller backbone and embedding dimension until full-scale WF42M is practical
- Practical local alternative under about 20GB: aligned WebFace4M
- Put or link a local WF42M identity-root source here via `scripts/import_wf42m.py`
