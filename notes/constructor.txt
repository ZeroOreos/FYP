# FYP Constructor

- Root: `Dataset/<dataset>/<transform_chain>_<base_root>`
- Naming: transform chain uses `__`, newest-leftmost, base root always rightmost
- Sample: `jpeg_q30__blur_sigma2_main`
- Pairs: `Dataset/pairs/<dataset_relative_base_root>_pairs.npz`
- `pairs.py`: `python3 pairs.py <dataset_dir>` -> pair file
- `modifier.py`: `python3 modifier.py <dataset_dir> --step <modifier_spec> [--step ...]` -> derived variant root with preserved structure
- `modifier.py`: rejects exact duplicate transform tokens already present in the input dataset chain
- `main.py`: `python3 main.py <dataset_dir>` -> pairs, embeddings, metrics, compiled summary
- `Models/<Model>/generate.py`: `<dataset_dir> <embeddings_out>` -> embeddings
- `Models/<Model>/evaluate.py`: `<pairs_file> <embeddings_file> <metrics_out>` -> metrics
- `transform.json`: stored in each generated variant root; `compiled_results.csv` reads and flattens it
- Reuse pairs, embeddings, metrics when present; always rebuild compiled summary
