# Backend Required Files

Purpose
- Record, for each backend model, which files under `Backends/` are actually needed by the current wrapper or generator path.
- Distinguish fixed required files from optional or stage-dependent files.

Method
- Traced direct path usage from:
- `Utility/runtime.py`
- `Models/*/generate.py`
- `Modifiers/attack/*/wrapper.py`
- `Models/protection/*/wrapper.py`
- supplemented with verified checkpoint paths already recorded in `notes/working/20_backend_adaptations.txt`

Scope note
- This file is about backend-side files under `Backends/`.
- It does not repeat the wrapper files under `Models/` or `Modifiers/`.
- "Required" means required by the current runnable wrapper path, not everything preserved for provenance.

- `dim`
- `mipgan` fallback mode

- `adaface`
- `magface`
- `fomm`
- `faceshield`
- Backends with broad backend-file dependency footprints:
- `reface`
- `mordiff`
- `falco`
- `m2f2_det`
