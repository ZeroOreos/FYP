# Preprocessing Guide

Purpose
- Implement research-aligned corruption transforms for FR robustness evaluation
- No training, no label changes, identity preserved
- Compatible with the shared pair system

General protocol
- Input images are already face-aligned and cropped
- Dataset structure remains `id_xxx/image files`
- Output keeps the same resolution and format as input
- Identity folders remain unchanged
- Execution must be deterministic given seed

Pair compatibility
- Do not regenerate pairs
- Do not rename or reorder images
- Only pixel content changes

Severity
- Exactly 5 discrete levels: `1..5`
- Higher level means stronger corruption
- Parameters are fixed per level

Required modifier interface
- `name: str`
- `severity_levels = [1,2,3,4,5]`
- `apply(image, severity: int, rng) -> image`
- Optional: `parameter_table[severity] -> dict`

Core corruption set
- Resolution / resampling downscale-to-upscale factors: `0.90, 0.75, 0.50, 0.35, 0.20`
- Gaussian blur sigma: `0.5, 1, 2, 3, 4`
- Motion blur length in pixels: `3, 5, 9, 15, 21`
- JPEG quality: `90, 70, 50, 30, 15`
- Illumination brightness factor: `0.85, 0.70, 0.55, 0.40, 0.25`
- Illumination contrast factor: `0.90, 0.75, 0.60, 0.45, 0.30`
- Illumination gamma: `0.8, 0.65, 0.5, 1.4, 1.8`
- Geometric misalignment rotation: `±3, ±6, ±9, ±12, ±15`
- Occlusion mask lower-face coverage percent: `30, 40, 50, 60, 70`
- Occlusion eye-band height percent: `10, 14, 18, 22, 26`
- Occlusion random block area percent: `5, 10, 15, 20, 25`

Constraints
- Must not modify labels or identity structure
- Must not perform detection or alignment
- Must not train or fine-tune models
- Must not combine corruption types unless requested
- Should preserve identity recognizability and cross-dataset comparability
