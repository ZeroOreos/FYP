# REFace And MorDIFF Purge Candidates

Purpose
- Identify redundant files inside the two backends we still care about: `reface` and `mordiff`.
- Keep the current runnable wrapper paths intact while trimming framework duplicates, training extras, eval bundles, and cached noise.

Ground rule
- This note is stricter than the general delete list.
- `Safe for current wrapper path` means the current `Modifiers/attack/reface/wrapper.py` or `Modifiers/attack/mordiff/wrapper.py` path should still work after deletion.
- `Conditional` means the current wrapper path probably still works, but we would be dropping extra upstream workflows, historical verification convenience, or portability.
