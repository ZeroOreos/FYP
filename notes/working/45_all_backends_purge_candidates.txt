Backend purge candidates across all backends
Date: 2026-04-08

Scope
- This note widens the trim pass to all backend source / asset trees, including active backends.
- Focus is `Backends/sources/**` and `Backends/assets/**`.
- Deliberately excludes `Models/**/testing` per user direction.
- Deliberately excludes `Backends/workdirs/**` from this list even though those trees contain many removable caches and package tests.

Method
- Checked the live wrapper / generator entrypoints first, then marked only files outside those paths.
- Buckets:
  - `safe now`: not on current wrapper path; docs, samples, notebooks, cache bookkeeping, duplicate or placeholder material
  - `conditional`: removable if we only preserve the currently verified route, but could matter for alternate modes, training, or future validation
  - `keep`: directly referenced by current wrapper / generator path
