# Backend Deletable Files

Purpose
- Build a delete-candidate list focused on files untouched by the active recognition and attack pipelines.
- Bias toward manual testers, sample media, duplicate archives, and non-working or redundant checkpoints.

Decision rule
- `Safe now`: not used by the active top-level pipeline and not needed by the current verified backend path.
- `Conditional`: not used by the active top-level pipeline, but still tied to backend verification, provenance, or optional standalone wrapper use.
- `Keep`: currently touched by the active pipeline or by the currently verified native backend path.

Safe now

Manual testing / benchmark files
- Delete:
- `Models/Arcface/testing/`
- `Models/FaceNet/testing/`
- `Models/InsightFace/testing/`
- Why:
- none of these trees are referenced by `main_recognition.py`, `main_attack.py`, `Utility/runtime.py`, or the active attack wrappers
- they are legacy manual test and benchmark helpers
- Extra note:
- `Models/FaceNet/testing/facenet_embeddings.npz`
- `Models/InsightFace/testing/main_antelopev2_embeddings.npz`
- `Models/InsightFace/testing/verification_pairs.npz`
- are generated/manual artifacts inside those testing trees, not pipeline outputs

Unused duplicate InsightFace pack
- Delete:
- `Backends/assets/recognition/insightface/models/buffalo_l/`
- `Backends/assets/recognition/insightface/models/buffalo_l.zip`
- Why:
- active recognition path uses `antelopev2`, not `buffalo_l`
- the only local references to `buffalo_l` are inside `Models/InsightFace/testing/`, which is already outside the active pipeline
- Estimated space:
- about `325M` for the unpacked folder
- about `275M` for the zip

Unused packed archive duplicate

- `Backends/assets/recognition/insightface/models/antelopev2.zip`

- about `344M`

- AdvFaceGAN broken zip: about `588M`
- InsightFace duplicate packs and zip: about `944M`
- doc / teaser assets: about `41M`
- total: roughly `2.3G`

Notes
- This list intentionally excludes venv contents. Those are much larger, but deleting them changes runtime capability, not just backend clutter.
- This list also excludes currently active checkpoints even if they are large.
