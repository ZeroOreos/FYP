- Add a second accelerator-oriented env for a model only when the shared MPS-oriented path is not enough
- Keep defense-model integration structurally consistent with the attack backends where practical:
- preserve third-party source snapshots under `Backends/sources/attack/<Name>_upstream/` and `Backends/sources/protection/<Name>_upstream/`
- keep mutable weights and support assets under `Backends/assets/attack/<method>/` and `Backends/assets/protection/<method>/`
- keep per-model runtimes under `Backends/workdirs/attack/<method>/` and `Backends/workdirs/protection/<method>/`

- protection-model device preference should default to `cuda -> mps -> cpu`

Licensing and source summary
- `simswap`: official `neuralchen/SimSwap` upstream is vendored locally; license is CC BY-NC 4.0, so treat it as non-commercial / research-use only
- `fomm`: official `AliaksandrSiarohin/first-order-model` upstream is vendored locally; license is MIT
- `faceshifter`: vendored local tree is `maum-ai/faceshifter`, which is an unofficial AEI-focused implementation rather than the canonical official release; license is BSD 3-Clause, but trustworthy pretrained weights were not established
- `reface`: official `Sanoojan/REFace` upstream is vendored locally; license is MIT; this is the strongest current replacement for the retired `faceshifter` slot
- `advfacegan`: preserved upstream tree is present locally and the wrapper is verified, but the vendored tree does not currently include a clear top-level license file; treat source provenance as present but license status as needing tighter confirmation
- `mordiff`: official upstream morphing script is vendored locally; the README states CC BY-NC-SA 4.0 and explicitly restricts use to research purposes rather than product development or competitions
- `dim`: native source import is from `zblasingame/Greedy-DiM`; the vendored repo license is MIT, but the runnable morphing code is encrypted and gated behind the CITeR release-form process
- `mipgan`: local tree currently contains the official NTNU public portal snapshot rather than the runnable native package; public users are instructed to sign the license form and request the password for the code-and-model archive
- `diffae`: vendored dependency used by `mordiff`; license is MIT

Working interpretation
- strongest permissive-license provenance in the active set is currently `fomm`, `reface`, and `diffae`
- strongest research-only / non-commercial provenance in the active set is currently `simswap` and `mordiff`
- most important remaining source / licensing ambiguity to clean up is `advfacegan`
- most important gated-release methods are `dim` and `mipgan`

Presentation notes

- headline ASR

- clean difficulty summary
- difficulty-stratified results
- Avoid presenting only one pooled ASR number
