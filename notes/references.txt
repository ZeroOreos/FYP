Core verification / recognition

- [active] Liu, Z., Luo, P., Wang, X., and Tang, X. (2015). Deep Learning Face Attributes in the Wild. ICCV.
  Link: https://openaccess.thecvf.com/content_iccv_2015/html/Liu_Deep_Learning_Face_ICCV_2015_paper.html
  Used for: CelebA dataset reference.
  Notes: Keep because the project appears to use CelebA-derived identities and images.

- [active] Schroff, F., Kalenichenko, D., and Philbin, J. (2015). FaceNet: A Unified Embedding for Face Recognition and Clustering. CVPR.
  Link: https://openaccess.thecvf.com/content_cvpr_2015/html/Schroff_FaceNet_A_Unified_2015_CVPR_paper.html
  Used for: FaceNet backbone reference and verification-embedding framing.
  Notes: Good baseline citation when discussing embedding-space verification.

- [active] Deng, J., Guo, J., Niannan, X., and Zafeiriou, S. (2019). ArcFace: Additive Angular Margin Loss for Deep Face Recognition. CVPR.
  Link: https://openaccess.thecvf.com/content_CVPR_2019/html/Deng_ArcFace_Additive_Angular_Margin_Loss_for_Deep_Face_Recognition_CVPR_2019_paper.html
  Used for: ArcFace-style recognition / verification backbone reference.
  Notes: This should replace the old incorrect ArcFace placeholder that duplicated the CelebA citation.

Attack evaluation / further reading

- [active] Chen, R. et al. (2021). SimSwap: An Efficient Framework For High Fidelity Face Swapping.
  Link: https://arxiv.org/abs/2106.06340
  Used for: constructor attack shortlist and `simswap` backend scaffold.
  Notes: Strong practical face-swap baseline for verification impersonation studies. License: non-commercial / research-use oriented.

- [active] Li, L. et al. (2020). FaceShifter: Towards High Fidelity And Occlusion Aware Face Swapping.
  Link: https://lingzhili.com/FaceShifterPage/
  Used for: constructor attack shortlist and `faceshifter` backend scaffold.
  Notes: Useful stronger face-swap baseline next to SimSwap. The local wrapper targets `maum-ai/faceshifter`, which is an unofficial AEI-only implementation. As of March 27, 2026, a trustworthy pretrained AEI checkpoint was not found from official or clearly maintained sources, so this method is retired from the active benchmark path and `reface` is used as its replacement.

- [active] Siarohin, A. et al. (2019). First Order Motion Model for Image Animation.
  Link: https://aliaksandrsiarohin.github.io/first-order-model-website/
  Used for: constructor attack shortlist and `fomm` backend scaffold.
  Notes: Canonical lightweight reenactment baseline. License: MIT.

- [active] Wang, Y. et al. (2021). HifiFace: 3D Shape and Semantic Prior Guided High Fidelity Face Swapping.
  Link: https://johann.wang/HifiFace/
  Used for: FaceShifter replacement candidate in the face-swap category.
  Notes: Strong paper-level alternative when a higher-fidelity swap baseline is needed. The project page presents `HifiFace-512`, but the code found was unofficial: `maum-ai/hififace` with a published pretrained checkpoint and BSD-3-Clause license.

- [active] Baliah, S. et al. (2024). Realistic and Efficient Face Swapping: A Unified Approach with Diffusion Models.
  Link: https://github.com/Sanoojan/REFace
  Used for: preferred modern face-swap replacement for FaceShifter and main diffusion-based face-swap candidate in this FYP.
  Notes: Official repo, MIT license, and the README states that checkpoints and dependencies were released on September 14, 2024.

- [active] Huang, Y. et al. (2025). AdvFaceGAN: a face dual-identity impersonation attack method based on generative adversarial networks. PeerJ Computer Science.
  Link: https://pmc.ncbi.nlm.nih.gov/articles/PMC12192821/
  Used for: motivating dual reporting of target success and source-identity preservation; also used for constructor shortlist and `advfacegan` backend scaffold.
  Notes: Strongly relevant to source-preservation-aware evaluation.

- [active] Kessler, C. et al. (2024). Face morphing attack vulnerability / pair-selection analysis paper.
  Link: https://pmc.ncbi.nlm.nih.gov/articles/PMC11142600/
  Used for: supporting clean-pair difficulty stratification.
  Notes: Helpful when justifying clean-margin bins and not relying on a single pooled ASR.

- [active] Venkatesh, S. et al. (2020). Worst-Case Morphs Using Wasserstein ALI and Improved MIPGAN.
  Link: https://research.utwente.nl/en/publications/worst-case-morphs-using-wasserstein-ali-and-improved-mipgan-2
  Used for: constructor attack shortlist and `mipgan` backend scaffold.
  Notes: Representative GAN-based morphing attack line for biometric verification.

- [active] Venkatesh, S. et al. (2024). MorDIFF: Recognition Vulnerability and Attack Detectability of Face Morphing Attacks Created by Diffusion Autoencoders.
  Link: https://publica.fraunhofer.de/entities/publication/704bfa7d-dc16-43fa-b933-e054396b4321
  Used for: constructor attack shortlist and `mordiff` backend scaffold.
  Notes: Representative recent diffusion morphing attack line.

- [active] Blasingame, Z. W. and Liu, C. (2024). DiM: Diffusion Morphs.
  Link: https://zblasingame.github.io/DiM/
  Used for: preferred modern morphing replacement / addition in the FYP shortlist.
  Notes: Strong current-trend morphing candidate if runnable code and checkpoints are available.

- [active] Grimmer, M. and Busch, C. (2024). LADIMO: Face Morph Generation through Biometric Template Inversion with Latent Diffusion.
  Link: https://arxiv.org/abs/2410.07988
  Used for: modern diffusion-based morphing fallback candidate if DiM remains practically gated.
  Notes: Official GitHub presence exists at `dasec/LADIMO`, but the repo README says to contact Christoph Busch to receive the official code and pre-trained models.

- [active] Kabbani, W. et al. (2025). StableMorph: High-Quality Face Morph Generation with Stable Diffusion.
  Link: https://arxiv.org/abs/2511.08090
  Used for: newest diffusion-based morphing candidate to evaluate if an openly runnable implementation is needed beyond DiM and MorDIFF.
  Notes: Recent IJCB 2025 / arXiv-era method. A public GitHub topic listing indicates a `christophbusch/StableMorph` repo exists, but local provenance and release openness still need confirmation before adoption.

Implementation provenance used in this repo

- [active] neuralchen/SimSwap repository.
  Link: https://github.com/neuralchen/SimSwap
  Used for: `Backends/sources/attack/SimSwap_upstream/`, local `simswap` wrapper, and verified swap generation in this repo.
  Notes: Official SimSwap repository. Local verification used the upstream repo plus its published ArcFace and generator assets, with small CPU-compatibility patches in the wrapper path.

- [active] AliaksandrSiarohin/first-order-model repository.
  Link: https://github.com/AliaksandrSiarohin/first-order-model
  Used for: `Backends/sources/attack/FOMM_upstream/` and the local `fomm` wrapper.
  Notes: Official FOMM repository. The local verified checkpoint came from a clean Hugging Face mirror after the original asset path produced corrupted downloads during setup.

- [retired] maum-ai/faceshifter repository.
  Link: https://github.com/maum-ai/faceshifter
  Used for: historical attack-shortlist provenance only.
  Notes: Unofficial PyTorch implementation of FaceShifter focused on AEI-Net. No trustworthy pretrained AEI checkpoint was found during setup, so the local backend and scaffold were removed from the active repo layout.

- [active] Sanoojan/REFace repository.
  Link: https://github.com/Sanoojan/REFace
  Used for: `Backends/sources/attack/REFace_upstream/`, `Modifiers/attack/reface/`, and the verified modern face-swap backend in this repo.
  Notes: Official REFace implementation. See `notes/working/20_backend_adaptations.txt` for the exact compatibility patches and runtime fixes.

- [active] Local implementation adaptation log.
  Link: `notes/working/20_backend_adaptations.txt`
  Used for: paper methods section, reproducibility appendix, and implementation honesty notes.
  Notes: This file records the exact local patches, cache seeding, CPU/offline adaptations, and verification commands used to make each upstream model run in this repo.
